# Godot import preset: pixel-art-3d

For pixel-art textures on 3D meshes with Nearest material filtering.

```bash
python3 godot_texture_import_presets.py apply PROJECT_DIR --preset pixel-art-3d --glob 'art/**/*.png'
python3 godot_texture_import_presets.py check PROJECT_DIR --preset pixel-art-3d --glob 'art/**/*.png'
python3 godot_texture_import_presets.py project-settings --preset pixel-art-3d
```
