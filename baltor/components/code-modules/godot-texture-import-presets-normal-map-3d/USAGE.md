# Godot import preset: normal-map-3d

For normal maps imported as RGTC with mipmaps.

```bash
python3 godot_texture_import_presets.py apply PROJECT_DIR --preset normal-map-3d --glob 'art/**/*.png'
python3 godot_texture_import_presets.py check PROJECT_DIR --preset normal-map-3d --glob 'art/**/*.png'
python3 godot_texture_import_presets.py project-settings --preset normal-map-3d
```
