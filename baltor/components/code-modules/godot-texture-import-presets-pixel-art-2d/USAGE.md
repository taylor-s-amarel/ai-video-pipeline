# Godot import preset: pixel-art-2d

For crisp 2D pixel art (Kenney Tiny/1-Bit, LPC, itch.io sheets).

```bash
python3 godot_texture_import_presets.py apply PROJECT_DIR --preset pixel-art-2d --glob 'art/**/*.png'
python3 godot_texture_import_presets.py check PROJECT_DIR --preset pixel-art-2d --glob 'art/**/*.png'
python3 godot_texture_import_presets.py project-settings --preset pixel-art-2d
```
