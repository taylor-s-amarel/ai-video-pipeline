# Easing functions (Penner set)

All 31 standard easing curves (sine to bounce, in/out/in-out) with name aliases, clamped evaluation, sampling and tweening for keyframes and text motion.

## Use

```python
import easing_functions
```

Placed by `baltor_catalog.py place easing_functions <step-dir>` under `.baltor/lib/easing-functions/`.
Add that directory to `sys.path` (or copy the module next to your script).

## Test

```sh
python3 -m pytest -q .
```
