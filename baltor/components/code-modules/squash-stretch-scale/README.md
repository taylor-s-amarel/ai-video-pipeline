# Squash and stretch scales

Volume-preserving stretch from velocity, impact squash with spring-back, and a dropped-object bounce track for cartoon, icon and stick-figure animation.

## Use

```python
import squash_stretch_scale
```

Placed by `baltor_catalog.py place squash_stretch_scale <step-dir>` under `.baltor/lib/squash-stretch-scale/`.
Add that directory to `sys.path` (or copy the module next to your script).

## Test

```sh
python3 -m pytest -q .
```
