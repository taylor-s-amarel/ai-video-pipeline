# Godot import preset: texture-3d

For photoreal PBR maps from Poly Haven/ambientCG (VRAM compressed, mipmaps).

```bash
python3 godot_texture_import_presets.py apply PROJECT_DIR --preset texture-3d --glob 'art/**/*.png'
python3 godot_texture_import_presets.py check PROJECT_DIR --preset texture-3d --glob 'art/**/*.png'
python3 godot_texture_import_presets.py project-settings --preset texture-3d
```
