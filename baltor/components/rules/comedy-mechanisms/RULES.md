# Comedy mechanisms

Source: Animation and Video Production Master Guide (v1.1, 10 October 2026), "Comedy mechanisms to develop" (line 101).

Name the mechanism a board relies on, make it playable the way the table says, and reject the board if it shows the failure in the third column.

| Mechanism | How to make it playable | Failure to reject |
|---|---|---|
| Status reversal | Establish who seems in control, then let their own choice reverse it | An unexplained stronger character solves everything |
| Dramatic irony | Show the audience a clue the character misses; let behavior build the gap | Concealing the only useful clue until the last frame |
| Overcomplicated solution | Each unnecessary improvement creates a new cost with visual consequences | Three versions of the same failed push |
| Literal interpretation | Define an instruction clearly, then exploit a coherent second meaning | Wordplay that the image cannot support |
| Opposed goals | Two characters pursue understandable incompatible goals in one space | One character exists only to be arbitrarily foolish |
| Contagious solution | A local fix spreads into a larger problem | Random chaos without object or causal continuity |
| Competent improvisation | A resourceful solution works, but changes the original objective | Failure after failure with no learning or agency |
| Delayed consequence | A seemingly minor early action returns at the worst possible moment | A new hazard appears with no plant |
| Scale mismatch | Ordinary objects become meaningful obstacles at a miniature scale | Size changes between shots to force a gag |
| Quiet button | After a decisive climax, a short secondary beat reframes the result | A long explanation after the joke already landed |

From the story contract: Not every story needs a moral, a villain, dialogue, or a countdown. Small personal stakes can work if the want and cost are clear. A lesson tacked onto the ending cannot replace causality. Suspense comes from uncertainty with understandable consequences, not merely dark music or a slowly opening door.

Related hook patterns whose catalogued use is comedy (a join made by the generator from the hook bank's Use column; each keeps its guard):

- H20 Expectation swap: "They brought a ladder. The problem needed a bridge." Guard: Keep the fictional solution coherent with the world.
- H41 Repetition with change: "The first two attempts teach you the rhythm. The third changes it." Guard: The third beat must alter an expectation, not repeat a color change.
- H50 Conflicting goals: "One character wants silence. The other runs a bell shop." Guard: Give both characters understandable motives.

BOXED IN lesson (see `story_contract_rules`): repeated unsuccessful attempts are not automatically an arc.
