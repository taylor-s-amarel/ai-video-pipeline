# Rules for the copy-ready task templates

Source: Animation and Video Production Master Guide (10 Oct 2026), "Copy-ready task templates" / "How to use the templates". The rules are the owner's sentences,
one per line.

1. These prompts are instructions for bounded work, not magic guarantees.
2. Fill their inputs with actual project data.
3. If an input is missing, mark it unresolved rather than inventing a source, license, test result, or customer preference.
4. Each prompt should result in a concrete artifact or decision that can be reviewed.
5. Keep the prompt, actual inputs, output, model/tool version when known, and human correction.
6. Do not infer that a successful output can be reproduced from the prompt alone.
7. Preserve generated assets and exact source bytes.
8. Use the prompts selectively; running all of them for every minor revision would waste effort.
