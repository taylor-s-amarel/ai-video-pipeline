# Source Watch plugin

Assemble from the catalogue: copy each command's `command.md` to `commands/<name>.md`, each subagent's `agent.md` to `agents/<name>.md`, the skill folder to `skills/monitor-sources-with-rss-for-agents/`, and the `require_digest_citations` hook's `settings.fragment.json` hooks block to `hooks/hooks.json`. Put the code modules under `.baltor/lib/` with `baltor_catalog.py place`.
