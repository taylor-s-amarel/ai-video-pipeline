## Task

> “Inspect the existing rig and animation. Replace uniform whole-body bobbing with a readable sequence of anticipation, weight shift, planted step, lifted step, turn, accent, and recovery. Preserve character identity and loop continuity. Vary wings or arms, head direction, and timing without breaking foot contact. ## What a useful result looks like (the guide's notes)

A dance loop should have an intentional center of gravity and a readable rhythm. Random parameter noise is not a substitute for choreography. The agent should be able to describe what the character is doing at each beat.
